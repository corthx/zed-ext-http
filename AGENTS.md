# Repository Agent Guide

This file provides guidance to AI coding agents when working with code in this repository.

## Context Loading

Load the following instruction files based on your current task:

- When working with git, commits, or branches: Read [.ai/git.md](.ai/git.md)
- When working with merge requests: Read [.ai/merge-requests.md](.ai/merge-requests.md)
- When working with issues: Read [.ai/issues.md](.ai/issues.md)
- When working with CI/CD pipelines or .gitlab-ci.yml: Read [.ai/ci-cd.md](.ai/ci-cd.md)
- When working with mise, tools, or task definitions: Read [.ai/mise.md](.ai/mise.md)

### Local Overrides

Read `AGENTS.local.md` if it exists. It is gitignored and holds rules for one working copy only.

## Code Architecture

### High-Level Structure

zed-ext-http is a [Zed](https://zed.dev/) extension for HTTP. The extension sources aren't in the repository yet: this
section describes them once they land.

**Documentation:**

- `README.md` - User-facing only: how to install and use the extension. Never document this repository or its
  processes there; that goes in `CONTRIBUTING.md`, `docs/` and `.ai/`.
- `CONTRIBUTING.md` - Entry point for contributors, linking to `docs/development.md`.

**Infrastructure:**

- `terraform/live/<unit>/` - OpenTofu root modules managing this project's GitLab configuration (labels, boards, bots,
  pipeline schedules), planned and applied by `.gitlab/ci/tofu.gitlab-ci.yml`. See
  [docs/infrastructure.md](docs/infrastructure.md).
- `renovate.json5` - Renovate's update policy. Renovate runs from this project's pipeline on a schedule
  (`.gitlab/ci/renovate.gitlab-ci.yml`); when adding a second copy of a pinned version, annotate it with a
  `# renovate:` comment. See [docs/infrastructure.md](docs/infrastructure.md#dependency-updates-renovate).

**GitHub mirror:**

GitLab is the source of truth; GitHub is a read-only push mirror. Never add anything that expects work to happen on
GitHub.

- `.github/workflows/release.yml` - On every mirrored version tag, creates the matching GitHub release, with notes
  generated by [git-cliff](https://git-cliff.org/) from `cliff.toml` (conventional commits grouped by type).
- `.github/ISSUE_TEMPLATE/config.yml` - Sends GitHub visitors to GitLab to open issues.
- `.github/FUNDING.yml` - GitHub Sponsors link.

**Configuration:**

- `mise.toml` / `mise.dev.toml` / `mise.ci.toml` / `.miserc.toml` - See [.ai/mise.md](.ai/mise.md) for the full mise
  configuration guide (envs, tool placement, task organization).
- `prek.toml` - Git hooks, run by [prek](https://prek.j178.dev/) at commit time and by the CI `lint` job.
- `.rumdl.toml` / `.ryl.toml` / `tombi.toml` / `terraform/.tflint.hcl` - Linter configs for Markdown, YAML, TOML and
  OpenTofu.

## Build & Test Commands

| Task                    | Command                           |
| ----------------------- | --------------------------------- |
| Lint the changed files  | `mise run prek:run`               |
| Lint every file         | `mise run prek:run:all`           |
| Validate the tofu units | `mise run tofu:lint:validate:all` |

**Always run `mise run prek:run:all` and confirm every hook passes before presenting an implementation for review.**
